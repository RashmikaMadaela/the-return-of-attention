# Session Time Controls - Quick Reference Card 🎯

## At a Glance

### What's New?
Two new buttons for ALL users during meditation sessions:
- **Time Skip** (⏭️) - Blue button
- **Fast Forward** (⏩) - Green/Orange button

---

## 🔵 Time Skip Button

### Appearance
```
┌──────────────────┐
│   ⏭️ Time Skip   │
└──────────────────┘
Color: Blue
```

### What It Does
- Instantly completes the current session
- Shows confirmation dialog (safety)
- Redirects to reflection page
- Saves session data

### When to Use
- Testing sessions quickly
- Need to end early
- Want to skip to reflection

### How to Use
1. Click "⏭️ Time Skip"
2. Click "OK" in confirmation
3. Session completes immediately

---

## 🟢 Fast Forward Button

### Appearance (Inactive)
```
┌──────────────────────────┐
│ ⏩ Fast Forward (10x)    │
└──────────────────────────┘
Color: Green
```

### Appearance (Active)
```
┌──────────────────────────┐
│ ⏩ Normal Speed          │
└──────────────────────────┘
Color: Orange
```

### What It Does
- Speeds up timer by 10x
- Timer decreases 10 seconds per tick
- Toggles between 1x and 10x speed
- PAHM clicks still work during fast-forward

### When to Use
- Want faster sessions
- Testing features
- Practicing at higher speed
- Short on time

### How to Use
1. Click "⏩ Fast Forward (10x)" → Turns orange, 10x speed
2. Click "⏩ Normal Speed" → Turns green, 1x speed
3. Toggle as many times as needed

## 📞 Need Help?

### Button Not Appearing?
- ✅ Check if session is **running** (not paused)
- ✅ Click "Start Meditation" first
- ✅ Refresh page if needed

### Fast Forward Not Working?
- ✅ Watch timer - should decrease by 10/tick
- ✅ Button should be orange
- ✅ Click again to toggle off

### Time Skip Not Completing?
- ✅ Click "OK" in confirmation
- ✅ Don't click "Cancel"
- ✅ Wait for redirect (3 seconds)

### PAHM Clicks Not Working?
- ✅ Timer must be running
- ✅ Fast forward doesn't block clicks
- ✅ Check reflection page for data
