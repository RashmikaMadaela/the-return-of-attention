# Audio Files Needed

Please add the following audio files to this directory:

## Required Files:
1. **bell.mp3** - 1-second meditation bell sound for session start/end
2. **5min-reminder.mp3** - Voice reminder for 5-minute intervals
3. **session-complete.mp3** - Completion sound for finished sessions

## Suggested Sources:
- Bell sounds: Use a singing bowl, meditation bell, or chime sound
- Voice reminders: Record a calm voice saying "Five minutes have passed" or similar
- Completion sound: Success chime or gentle bell sequence

## Audio Requirements:
- Format: MP3 or WAV
- Duration: 1-3 seconds for bells, 3-5 seconds for voice reminders
- Quality: Clear, calming, not jarring
- Volume: Moderate level, not too loud or soft

## Usage:
These audio files will be used in the meditation timer for:
- Session start notifications
- Periodic time reminders
- Session completion alerts
