Happiness Calculation Formula & Logic

Present Attention Happiness Model (PAHM) - Technical Documentation

Architecture: Single-Point v3 Strict Mode

Data Requirements (STRICT Mode)

Mandatory: Both questionnaire AND self-assessment must be completed to enable calculation.

Optional Enhancement: Practice sessions enhance scores but are not required for basic calculation.

Component Calculations

1. Current State Assessment

Source: Questionnaire responses + emotional notes

Base Score = 0
+ Emotional Awareness × 8
+ Sleep Pattern × 6
+ Physical Activity Bonus
• very_active: 25 points
• moderate: 15 points
• light: 8 points
• sedentary: 0 points
+ Work-Life Balance
• excellent: +20 points
• good: +12 points
• struggle: -10 points
+ Stress Response
• manage well: +15 points
• usually manage: +8 points
• overwhelmed: -15 points
+ Recent Mood Average (from notes) × 8

2. Attachment-Based Happiness

Source: Self-assessment attachment patterns

Attachment Score = Sum of attachment penalties
Non-Attachment Bonus = Non-attachment categories × 12

Final Score = Attachment Score + Non-Attachment Bonus

Per category scoring:
• "none" (non-attachment): +12 bonus
• "some" attachment: -7 penalty
• "strong" attachment: -15 penalty

PAHM Score = Assessment Foundation + Practice Realization

Final Weighted Calculation

Final Happiness Score = Round(
  (PAHM Score × 0.25) + 25% Primary component
  (Attachment Score × 0.20) + 20% Attachment flexibility
  (Emotional Stability × 0.18) + 18% Stability progress
  (Current State × 0.12) + 12% Current mood/state
  (Emotional Regulation × 0.10) + 10% Regulation skills
  (Mind Recovery × 0.08) + 8% Recovery effectiveness
  (Social Connection × 0.04) + 4% Social bonds
  (Practice Consistency × 0.03) 3% Consistency
)

Key Logic Notes

  • PAHM (Present Attention Happiness Model) is the core component at 25% weight
  • Attachment patterns heavily influence happiness (20% weight)
  • Practice sessions enhance but don't enable calculation
  • Both assessments required - questionnaire provides baseline, self-assessment measures attachment
  • Negative scoring possible for high attachment or poor stress responses
  • Quality over quantity - session quality multiplies benefits
  • Present-moment awareness emphasized as primary happiness driver
  • Non-attachment wisdom receives significant bonuses
  • Emotional regulation critical for sustained happiness
  • Consistent practice amplifies all benefits
